# Watch Tracker

## Overview
A personal project to log and track my watch collection, built while learning Python.
Started as a simple way to catalog my watches, and expanding into accuracy tracking
and marketplace price monitoring as I go.

## Current features (Phase 1)
- Watch and Collection classes (add, remove, view)
- Export collection to .txt or .json

## Roadmap
- **Phase 2** - Track daily accuracy/drift readings per watch, calculate a "health score"
- **Phase 3** — Move to a real database, build an API, add price lookup to compare
  current market prices against retail price
- **Phase 4 (stretch)** — Containerize and deploy with Docker/Kubernetes
- **Future ideas** — Price history charts to visualize how a watch's value has changed
  over time
